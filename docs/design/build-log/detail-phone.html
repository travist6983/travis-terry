##The problem

Coding agents tend to fail the same way, and it’s rarely the model’s fault. The agent reads a bug, makes a change, sees something green and says it’s done.

A smarter model doesn’t fix that. The system around the model has to know what “done” means.

##What the kit did

Every agent in the kit is a loop, not a prompt. The reference loop is the defect loop:

defect-loop.recipe
intake → repro → fix →
verify ∥ regression → pre-pr →
ship → prod-verify
